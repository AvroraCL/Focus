# HUD 预设

原有“极简、经典、专业分析”继续保留，新增 6 套，共 9 套内置预设。

| 预设 | 默认位置 | 画布尺寸 | 用途 |
| --- | --- | --- | --- |
| 瑞士极简 | 左上角 | 200 × 112 | 纸白底、黑色帧率和红色焦点，附帧时间 |
| 竞技横条 | 顶部居中 | 660 × 88 | FPS、1% Low、0.1% Low、帧时间与 30 秒趋势 |
| 硬件侧栏 | 右上角 | 264 × 350 | GPU / CPU 负载、温度、功耗、频率，以及 RAM / VRAM |
| 温控面板 | 右下角 | 304 × 240 | GPU / CPU 温度、功耗、温度条及 GPU 热点 |
| 跑分分析 | 左下角 | 536 × 284 | 帧率统计、30 秒帧时间图、最大帧时间及会话时长 |
| 底部信息带 | 底部居中 | 620 × 44 | 低高度的 FPS、帧时间、GPU / CPU 与内存信息带 |

在“配置文件 → 内置预设”点击“使用预设”立即应用；点击“编辑”会创建可修改副本。搜索支持预设名称和用途说明。位置、缩放、字体、颜色、阈值均可在编辑器调整。

竞技横条默认在 FPS 低于 60 时变色；温控面板默认在 GPU ≥ 80°C、CPU ≥ 85°C、GPU 热点 ≥ 95°C 时变色。这些是可编辑的提示条件，不代表针对某型号硬件验证过的温度上限。没有对应传感器或未开始帧采集时显示“—”。

曲线使用自动纵轴，展示最近 30 秒采样；预设不会启动录制。跑分面板的会话时长与其他预设使用同一个 SessionTime 指标。

## 开发验证与导出

```powershell
& 'C:/Program Files/dotnet/dotnet.exe' run --project docs/tools/PresetPreview/PresetPreview.csproj -c Release -- artifacts/hud-presets
```

工具使用真实 HUD 渲染器，检查规范化后的边界与文字尺寸，渲染示例数据和空数据版本，导出可直接导入的 JSON、透明 PNG 与汇总图。汇总图明确标注示例数据，不是游戏实测。

同时修复编辑器/缩略图将固定文字标签误判为缺失指标、导致文字变暗的问题。HUD 本身的真实缺失指标仍正常变暗。
